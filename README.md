# Customer Shopping Behavior Analysis

## About the Project

This project analyzes customer shopping behavior using Python, SQL, PostgreSQL, and Power BI.

The main goal is to understand how customers purchase products and find useful business insights from the data.

## Tools Used

- Python
- Pandas
- PostgreSQL
- SQL
- Power BI

## What I Did

### Python
- Loaded and explored the dataset
- Checked for missing values
- Cleaned the data
- Standardized column names
- Created age groups
- Converted purchase frequency into days
- Removed duplicate information

### SQL
I used SQL to analyze:

- Revenue by gender
- Customer spending
- Product ratings
- Shipping types
- Subscription behavior
- Discount usage
- Customer segments
- Top products
- Repeat customers
- Revenue by age group

### Power BI

I created an interactive dashboard to analyze:

- Total customers
- Average purchase amount
- Average review rating
- Sales by category
- Revenue by category
- Sales by age group
- Revenue by age group
- Subscription status

## Key Insights

- The dataset contains **3,900 customer records**.
- Average purchase amount is approximately **$59.76**.
- Average review rating is approximately **3.75**.
- **Clothing** is the highest-performing category.
- **Young Adults** contribute the highest sales and revenue.
- Around **27% of customers are subscribers**.
